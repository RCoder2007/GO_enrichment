# Generating Strand-Specific Promoter Coordinates from Human Gene Annotations

## Project Overview

This workflow extracts transcription start site (TSS) locations from human gene annotation data and constructs strand-aware promoter intervals extending 500 bp upstream of each TSS using `bedtools`.

The generated promoter regions can later be used for analyses such as motif discovery, transcription factor binding analysis, and functional enrichment studies.

---

# Project Files

| File Name | Purpose |
|---|---|
| `tss_reference_sites.bed` | BED file containing processed TSS positions with strand information |
| `upstream_promoter_regions.bed` | Strand-aware upstream promoter intervals generated from TSS coordinates |

# Input Resources

## Human Reference Genome

The human reference assembly (`hg38.fa`) was obtained from the UCSC Genome Browser:

```text
https://hgdownload.soe.ucsc.edu/goldenPath/hg38/bigZips/
```

## Gene Annotation Dataset

```text
human_gene_annotation.tsv.gz
```

---

# Preparing Genome Size Information

First, a FASTA index was generated for the reference genome:

```bash
samtools faidx hg38.fa
```

Chromosome sizes required by `bedtools` were then extracted:

```bash
cut -f1,2 hg38.fa.fai > hg38.genome
```

---

# Extracting TSS Coordinates

The annotation table was converted into BED format using an AWK script.

Generated BED structure:

| Column | Content |
|---|---|
| 1 | Chromosome |
| 2 | TSS coordinate |
| 3 | TSS end position |
| 4 | Feature identifier |
| 5 | Placeholder |
| 6 | Strand direction |

Command:

```bash
zcat human_gene_annotation.tsv.gz | \
awk 'BEGIN{OFS="\t"}
NR>1{

    if($8==-1 || $8=="" || $7=="")
        next

    chrom="chr"$5

    if(chrom=="chrMT")
        chrom="chrM"

    tss=$8 + 0

    strand="+"
    if($6==-1)
        strand="-"

    print chrom, tss, tss+1, chrom"@"tss"-"(tss+1)"|"$7, ".", strand
}' > tss_reference_sites_raw.bed
```

Entries corresponding to chromosomes absent from the genome assembly were filtered out:

```bash
grep -Fwf <(cut -f1 hg38.genome) \
tss_reference_sites_raw.bed \
> tss_reference_sites.bed
```

---

# Constructing Upstream Promoter Regions

Promoter intervals were generated by extending coordinates 500 bp upstream relative to strand orientation.

```bash
bedtools slop \
-i tss_reference_sites.bed \
-g hg38.genome \
-l 500 \
-r 0 \
-s \
> upstream_promoter_regions.bed
```

---

# Strand-Sensitive Promoter Generation

The `-s` parameter in `bedtools slop` ensures that upstream regions are computed according to gene orientation:

- Genes on the `+` strand are extended toward lower coordinates
- Genes on the `-` strand are extended toward higher coordinates

Example entry:

```text
chrM    4400    4901    chrM@4400-4401|MT-TQ    .    -
```

Since this gene is located on the negative strand, the promoter region expands toward increasing genomic positions.

---

# Final Output

The resulting file:

```text
upstream_promoter_regions.bed
```

contains strand-aware promoter coordinates suitable for downstream genomic and regulatory analyses.
